🕊️ Fetihler Koordinasyon

Fetihler Koordinasyon, bir yardım kuruluşunun köy ve bölgelere yardım dağıtımlarını planlayıp takip edebilmesi için geliştirilen bir C# WinForms uygulamasıdır.
Uygulama, görevli personel, araç ve yük dağıtımını MSSQL veritabanı üzerinde yönetir.

🚀 Özellikler

👥 Kullanıcı Yönetimi: Görevli, sürücü, yönetici gibi farklı kullanıcı rolleri

🚗 Araç Kayıtları: Araçların kapasite, plaka ve durum takibi

📦 Yük Planlama: Araç başına taşınacak yük miktarı ve içerik bilgileri

📍 Rota ve Görev Yönetimi: Hangi aracın hangi köye gideceği, görev atamaları

🤝 Muhtar Bilgileri: Köy muhtarlarıyla iletişim bilgileri kayıtları

📝 Raporlama: Görev ve imza raporları (PDF / Excel aktarımı)

📊 Excel Aktarımı: Verilerin dışa veya içe aktarılması (rapor, analiz, yedek)

✍️ İmza Kaydı: Görev tamamlandığında muhtar veya görevli imzası alınabilir

🔔 Olay Tabanlı İş Akışı: Görev atama, yükleme veya raporlama gibi olaylar sistem içinde tetiklenir

⚙️ Teknik Bilgiler

Platform: C# WinForms (.NET Framework / .NET 6+)

Veritabanı: Microsoft SQL Server

Mimari: Katmanlı yapı (UI – Business – Data Access)

Olay Yönetimi: Event-driven yaklaşımı (görev atama, rapor üretme vb.)

Raporlama: Excel (ClosedXML / EPPlus) ve PDF çıktıları

Veri Erişimi: ADO.NET / Entity Framework
